# 多设备 Hub 同步

设置中的「多设备同步」支持仅本机、连接 Hub、本机托管 Hub。默认仅本机，不监听网络端口，也不上传统计。同步设置通过本页的「应用同步设置」立即生效。

## 让 Windows 托管 Hub

1. 选择「本机托管 Hub」，填写监听端口，默认为 `17321`。
2. 点击「生成新密钥」，再点击「应用同步设置」。共享密钥需为 16–256 个可打印 ASCII 字符，不含空格。
3. 使用「复制密钥」，在其他设备的 Token Monitor 中选择「连接到 Hub」，填写本页列出的地址和相同密钥。每台设备使用不同的设备 ID。

Hub 监听本机 IPv4 网络接口。Windows 防火墙若阻止传入连接，需要允许此程序在所用网络接收连接。程序不自动修改防火墙、路由器或 VPN。关闭设置窗口后继续运行，真正退出额度工具、关机或休眠期间无法服务其他设备。

内置 Hub 使用 HTTP，不提供内置 TLS。HTTP 上的统计和共享密钥不会被加密；仅在可信网络或可信 VPN 中使用。跨网络可使用 Tailscale / ZeroTier，或由用户配置 HTTPS 反向代理。只有知道密钥的客户端才能读取和上传统计；`/api/health` 是公开健康检查。

## 连接已有 Hub

选择「连接 Hub」，输入 `http://主机:端口` 或 `https://主机:端口` 和共享密钥，再应用设置。地址只接受 HTTP(S) 源站，不接受用户名、密码、查询参数或路径前缀。

客户端约每 10 秒重新扫描和交换一次；首次补齐扫描及网络请求会增加间隔。网络失败会保留上次成功读取的汇总，后续周期重试。来自不同 Hub 地址的缓存不会混用。所有设备应连接同一个 Hub；分别托管多个 Hub 不会自动互相交换。

## 统计与历史

同步页显示所有已保存设备的今日、本月和累计 Token，以及标准 API 等价费用估算。历史支持每日/月度切换和翻页。未知价格不计入费用；这些金额不是订阅实际扣费或完整账户账单。设备停止上报后保留已记录的统计，并标明旧数据状态。

本机同步采集基于现有 Codex JSONL 扫描器，首次最多读取其支持的近 365 天记录。启用同步后，独立的每日历史档案保留已经观察到的会话/日期/模型累计值；源日志删除或扫描缓存清理不会自动删除档案。档案不保存提示词、回复、工具输出、会话标题、项目路径或登录 Token。累计值不会因后续较小或不完整的扫描而降低，因此它也不支持把手动删日志当成撤回已统计用量。

不能补回从未采集且已经丢失的日志。详细每日历史的同步窗口为最近 370 天，月度汇总可保留更早月份；本机累计始终标记为未确认完整生命周期。原有「Codex 用量」页仍显示本机日志分析，多设备数据在「多设备同步」页查看。

Hub 按设备 ID 保存最新快照；同一设备重复上传会替换快照。不同设备的用量直接相加，**不会跨设备去重**。不要让多个采集器把同一份复制日志当成独立用量上传。同一设备停止采集某工具时，保留该工具之前上传的计数及可按工具归属的历史。

资源上限：单次上传 2 MiB，最多 128 台设备，Hub 持久化文件最多 16 MiB。本机历史档案最多 180,000 条每日分组、64 MiB；达到上限时停止更新并保留上次结果，不静默清空。详细模型归属不足时不推测分配。项目统计的覆盖状态标为不完整。

## 兼容范围

基础协议参照 [Token Monitor 的 API](https://github.com/Javis603/token-monitor/blob/8c50fcc9571710dbebf9ca9b56c1c371865ec03a/docs/API.md)，这是截图所示的项目，和原始 steipete/CodexBar 不同。

内置 Hub 提供健康检查、Bearer / `X-Token-Monitor-Secret` 鉴权、完整设备快照上传、汇总、设备记录、历史和 SSE 完整快照。增量上传返回 404，供支持回退的客户端改用完整上传；新版 SSE 请求使用旧版完整帧回退。最多同时保持 4 个 SSE 连接，其他工作线程保留给普通请求。

本版不实现共享会话标题、自定义价格/模型别名、订阅账本或 Hub 之间的联邦同步；能力端点明确关闭标题和共享设置。Windows 自身不上传账户登录凭据或额度接口响应；来自其他设备的额度观察按提供方及账户标识保留最新值，不相加百分比。具体 macOS Token Monitor 版本的实机互通仍需实际连接验证；不能将协议适配等同于所有版本的所有扩展功能均受支持。

## 数据位置与凭据

用户数据目录中分别保存 `hub-settings.json`、`hub-devices.json`、`hub-local-history.json`、`hub-scan-cache.json` 和 `hub-remote-cache.json`。设置文件不包含共享密钥；共享密钥保存在 Windows 凭据管理器的独立条目 `CodexQuotaBar.SyncHub.Secret` 中，与 Codex 登录及 DeepSeek 凭据分开。

仅切换到「仅本机」不会删除档案。常规更新保留这些数据；执行明确选择删除用户数据的卸载操作时，才清理本应用的 Hub 文件和独立凭据。
