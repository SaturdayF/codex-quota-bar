# v0.1.0

2026-11-01 封存的首个功能基线。实现范围见 [CHANGELOG](../../CHANGELOG.md) 与 [README](../../README.md)。

应用图标采用用户选定的 E 方案：白色底，大绿环与更小蓝环相扣，灰色弧段示意已用额度，没有 Q 尾笔。

发布包含完整 Windows x64 程序包、安装/卸载脚本、必要运行时和文档插图。发布 ZIP 同时提供 SHA-256 校验文件。对应 Git 标签为 `v0.1.0`；后续修改使用 `0.2.0`，不替换本版本的标签或发行文件。

验证包含离线额度与子进程协议检查、图形与配置检查，以及本机两屏的布局、右键设置恢复、首帧居中和色板操作。卸载预演不得删除当前用户安装；原生截图和动画中的额度均为模拟数据。真实服务端重置没有为测试而触发。
