# Codex Quota Bar 0.3.8

Windows 10/11 x64 原生程序。

## 本版更新

- 详情面板标题改为「DeepSeek · 当日消耗」，余额整数位放大，小数部分与整数底部对齐并收紧间距。
- 详情中的费用保留两位小数；摘要和模型明细显示输入命中、未命中、输出与请求数，Token 数量加入千分位。
- 弹出详情新增每小时 Token 用量，柱状图悬停卡片展示该小时的输入命中与未命中，并按 K/M/B/T 单位显示。
- 详情右上角新增 API Key 下拉，可按平台提供的 Key 名称在「全部 API Key」与单个 Key 之间切换花费与用量统计。
- 任务栏组件的余额和今日花费更新时播放数字过渡动画：旧值向下位移、缩小并淡出，新值由小变大从上方淡入。
- 「立即刷新」会重播余额与今日花费的过渡动画；动画播放时组件闪一下透明白色，可在 DeepSeek 设置中关闭。

## 已实现功能

- 在任务栏显示 Codex 5 小时和周额度，支持独立开关、套餐默认值及悬浮详情。
- 显示 DeepSeek 账户余额、北京时间当日消费，以及按模型汇总的费用、请求数和输入/输出 Token；支持跟随 Harness 或独立显示。
- 支持多屏、任务栏图标避让、拖动布局、七种额度样式、配色、缩放、透明度及自动/手动刷新。
- 提供可选择安装目录的安装包、便携 ZIP 和 SHA-256 校验文件，支持设置中的卸载入口。
- 支持浅深色外观、托盘入口、DeepSeek 每小时消耗图，以及 Edge / Chrome 凭证自动获取和手动填写。
- 凭证获取成功后自动保存并刷新查询，成功与失败均有按内容调整大小的提示弹窗。

自动获取凭证适用于 Edge / Chrome 标准用户目录中的受支持本地存储。无痕窗口、自定义用户数据目录或存储格式不兼容时，可手动填写平台 userToken。凭证保存在 Windows 凭据管理器。
