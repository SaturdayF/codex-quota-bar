# Codex Quota Bar 0.3.4

Windows 10/11 x64 · C++ 原生程序 · 最新稳定版

## 本版更新

- 设置默认浅色，可切换深色；安装与卸载向导采用浅色。
- 设置、顶栏与悬浮详情使用系统实时毛玻璃，背景随窗口移动及后方内容变化更新。
- 侧栏贯穿窗口高度，隐藏顶栏应用文字与图标，保留窗口拖动、缩放和系统按钮。
- 下拉列表采用圆角玻璃弹层及当前选项标记；输入框、按钮与预览区统一半透明样式。
- 输入框保留中文编辑、文本选择、撤销和凭证遮蔽；字体统一为无衬线字体。
- 滑动条使用有色轨道和圆形滑块，右侧使用细长滚动条。
- 程序运行时显示托盘图标，点击打开设置，右键可打开设置或退出；Explorer 重启后恢复图标。
- DeepSeek 相关设置增加“显示 DSH 图标”开关，关闭后保留余额、消费与详情，组件宽度自动缩短。
- README 更新为当前版本界面，最新版与稳定版均指向 0.3.4。
