# Codex Quota Bar 0.4.1

Windows 10/11 x64 原生程序。

## 本版更新

- 设置新增「Codex 用量」页，显示近 7 / 30 天本地 Token、会话数量和标准 API 等价费用估算，支持按天/小时趋势、年度活跃热力图，以及模型、项目、会话和可确认的账户归属分组。
- 额度详情支持接口返回的月度及模型专属额度，新增按账户、工作区和重置周期区分的额度采样历史、剩余额度曲线及均匀消耗参考线。
- 本地用量采用增量读取和重复会话去重；未知价格、未覆盖记录和无法确认的继承边界单独标明。
- 前台应用全屏时隐藏所在显示器的任务栏组件和悬浮详情，退出全屏后恢复。高级设置新增更新检查，安装版可确认后下载、校验并覆盖更新到原目录。
- 新增「多设备同步」设置，支持仅本机、连接已有 Hub、由本机托管 Hub。支持共享密钥生成和复制、独立设备 ID、端口和连接状态显示，界面沿用系统毛玻璃。
- 新增按 Token Monitor 基础协议交换设备用量的原生 HTTP 客户端及 Hub。提供健康检查、鉴权、完整快照上传、设备/用量/历史读取及 SSE 完整快照；重复设备上传替换原快照。
- 同步页显示各设备汇总的今日、本月和已保存累计 Token、费用估算，以及可按日/月翻页的历史。断网时保留上次成功读取的汇总。
- 新增独立每日历史档案和 Hub 设备持久化，保留已采集记录；共享密钥保存在 Windows 凭据管理器的独立条目中。

## 功能与数据范围

保留 Codex 5 小时/周额度、DeepSeek 余额与消费明细、多屏布局、拖动避让、外观配色和透明度、托盘及自动/手动刷新功能。

统计仅覆盖已采集记录，不能恢复从未读取且已丢失的日志。费用为标准 API 等价估算，不是实际账单；跨设备的重复日志会重复相加。详细每日历史同步最近 370 天，月度汇总和本机档案受存储上限约束。原有「Codex 用量」页保持本机统计，多设备汇总在同步页查看。

内置 Hub 随程序运行，退出程序即停止；HTTP 不加密，跨网络使用可信 VPN 或 HTTPS 反向代理。本版提供基础用量协议适配，不包括共享标题、自定义价格/别名和订阅账本。macOS 具体版本的实机兼容性尚未确认。

设置、登录信息及统计档案在常规更新时保留。使用方法与资源限制见 [多设备 Hub 同步](https://github.com/SaturdayF/codex-quota-bar/blob/v0.4.1/docs/HUB_SYNC.md)。
