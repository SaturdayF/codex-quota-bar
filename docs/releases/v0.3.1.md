# Codex Quota Bar 0.3.1 · 修订封存（v0.3.1）

- 修复切换设置栏目时的白块残影，隐藏栏目控件不再参与当前页布局，页面与边框统一重绘。

- 松手后平滑吸附、回位或交换位置，支持即时重新拖动，遵循系统动画设置。
- 兼容平台数值型小时分桶，修复余额正常但当日消费、Token 明细为空的问题；细分读取错误提示。
- 修复双组件空闲时反复调整层级引起的闪烁；新增默认开启的图标自动避让，可在常规页关闭。
- 拖动可跨越任务栏图标和覆盖另一组件，松手时按重叠面积 50% 阈值判断交换或回位；空位不足时联合重排。
- 新增 DeepSeekHarness 余额和当日消费组件，平时待机，随 Harness 桌面应用启动显示、退出关闭。
- 可选“未启动时也显示余额”，默认关闭；开启后不依赖 Harness 运行，可独立显示和刷新余额与账单。
- 悬浮查看各模型费用、请求数、缓存命中 / 未命中输入和输出 Token，支持滚轮翻阅较多模型。
- 使用平台登录态读取同一账户的余额和账单；无需 API Key，不收集账户密码。
- 凭证存入 Windows 凭据管理器，JSON 不保存密钥；保留手动刷新、失败退避与明确错误状态。
- 保留已封存的 0.2.2 标签及发布文件。

数据采用平台实际账单，不按单价或余额变化估算；统计账户用量，按北京时间 UTC+8 切日，不混合不同币种。平台账单接口未经公开文档化，可能变化或拒绝访问。

- 新增便携版“卸载程序”按钮：确认后清理发布文件、本工具设置、启动项与 DeepSeek 凭证，保留额外文件。
- Windows 拒绝任务栏子窗口时使用居中的置顶备用窗口，宿主未变化时不反复重建。

提供可修改安装路径的 Setup EXE、便携 ZIP 和 SHA256SUMS.txt；无需额外运行库。

本次修订包含固定画布与合成视口的设置滚动修复，滚轮不再逐个定位控件，覆盖部分裁剪、往返滚动、小步输入及边界场景。

自动化验证使用模拟协议响应和模拟额度 UI，另已完成一次真实账户的余额、费用和 Token 接口只读验证。程序尚未代码签名，平台账单接口可能随服务变更。

封存标签：`v0.3.1`；源码提交：`{SOURCE_COMMIT}`。历史 `v0.3.0` 标签保持不变。后续功能变更使用下一版本。

验证：430 项核心检查、243 项 UI 检查（含 28 项 DeepSeek UI 检查）；安装版自定义中文路径安装/卸载、便携版中文/空格/单引号路径卸载通过，保留无关文件。程序仅导入 Windows 系统 DLL，无 CLR 运行时。

兼容性范围：本机 Windows 桌面与合成多 DPI 回归已验证；不能保证所有 Windows 版本、第三方任务栏或企业安全策略下行为一致。便携卸载需要系统 PowerShell；被策略阻止时可退出后手动删除。
