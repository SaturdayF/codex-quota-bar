# Codex Quota Bar 0.4.3

Windows 10/11 x64 原生程序。

## 本版更新

- Codex 用量支持本机日志、全部设备和指定设备切换；共享来源显示今日、本月、累计统计，以及已同步的模型、项目、会话、设备和账户额度。
- 补齐 Windows 归一化账户额度、会话/模型 Token 分项、项目标签和采集状态上传；接收保留每设备统计、历史和额度，远端读取独立于本地扫描与上传。
- Codex 详情的“今日 Token”加入逐位数字滚动动画，打开时滚入当前用量，数值更新时平滑衔接；遵循当前样式的动画开关和 Windows 动画设置。
- Codex 用量页新增导出 CSV 与导入 CSV，备份全部已采集用量明细、Token 分项、费用、分组及额度采样历史；导入校验后合并保存，重启和刷新后继续读取，重复恢复不累加相同记录。
- 移除用量页顶部记录覆盖提示和额度历史下方的采样时间、曲线说明文字。

## 功能与数据范围

包含 Codex 额度与用量、采样历史、多设备 Hub 同步、DeepSeek 余额与用量、多屏、外观、全屏隐藏和自动更新。设置与详情沿用系统毛玻璃。

共享统计来自各设备上报的 Codex 汇总与历史，保留上报日期口径，不跨设备去重。缺少来源的字段保持未知，累计会话明细可能不完整。账户额度分别展示，不相加。费用为标准 API 等价估算，不代表订阅实际扣费。CSV 备份与按小时分析使用本地记录。

连接方式和兼容范围见 [Hub 同步说明](https://github.com/SaturdayF/codex-quota-bar/blob/v0.4.3/docs/HUB_SYNC.md)。
