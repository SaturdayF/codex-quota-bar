# Codex Quota Bar 0.3.5

Windows 10/11 x64 原生程序。

## 本版更新

- DeepSeek 支持从 Microsoft Edge 最近使用的普通配置中一键获取平台登录凭证，验证成功后自动保存并刷新查询。
- 获取成功时显示确认弹窗；失败时提醒检查是否已在 Edge 网页版登录 DeepSeek 平台。
- 提示弹窗支持浅深色外观、文本自动换行及按内容调整高度；凭证填写说明支持拖动、回车和 Esc 关闭。
- DeepSeek 详情展示北京时间当日每小时消耗柱状图。

## 已实现功能

- 在任务栏显示 Codex 5 小时和周额度，支持独立开关、套餐默认值及悬浮详情。
- 显示 DeepSeek 账户余额、北京时间当日消费，以及按模型汇总的费用、请求数和输入/输出 Token；支持跟随 Harness 或独立显示。
- 支持多屏、任务栏图标避让、拖动布局、七种额度样式、配色、缩放、透明度及自动/手动刷新。
- 提供可选择安装目录的安装包、便携 ZIP 和 SHA-256 校验文件，支持设置中的卸载入口。
- 支持浅深色外观、托盘入口、DeepSeek 每小时消耗图，以及 Edge 凭证自动获取和手动填写。

自动获取凭证适用于 Edge 标准用户目录中的受支持本地存储。无痕窗口、自定义用户数据目录或存储格式不兼容时，可手动填写平台 userToken。凭证保存在 Windows 凭据管理器。
