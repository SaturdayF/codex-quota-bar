# Codex Quota Bar 0.3.5

Windows 10/11 x64 原生版本。本版本为最新稳定版。

- DeepSeek 一键获取凭证使用普通 Edge 网页和本机登录态，无需安装扩展或 WebView2；验证成功后自动保存并刷新查询。
- 成功时显示确认弹窗；失败时提示检查是否已在 Edge 网页版登录 DeepSeek 平台。弹窗统一为浅深色毛玻璃样式，高度随文字数量调整。
- DeepSeek 详情增加北京时间当日每小时消耗柱状图。
- 凭证填写说明采用统一毛玻璃弹窗，支持拖动、回车和 Esc 关闭。

自动获取目前支持 Edge 标准用户目录中的 LevelDB 存储，不支持 InPrivate、自定义用户数据目录或 SQLite 存储。也可手动填写 userToken。

验证：469 项核心检查、54 项 DeepSeek UI 检查；安装和便携包使用隔离目录验证。预览使用模拟数据。省电模式下系统关闭毛玻璃效果，界面回退为纯色背景。

下载 Setup EXE 安装，或完整解压 Portable ZIP 使用；无需额外运行库。SHA256SUMS.txt 用于核对下载文件。
