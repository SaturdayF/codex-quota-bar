# Codex Quota Bar 0.3.0（开发草案，尚未发布）

- 新增 DeepSeek 设置与独立任务栏显示：账户余额、北京时间当日消费。
- 悬浮查看各模型费用、请求数、缓存命中 / 未命中输入和输出 Token，支持滚轮翻阅较多模型。
- 平台账单模式统一使用同一平台凭证；API Key 模式只显示余额，不伪造消费。
- 凭证存入 Windows 凭据管理器，JSON 不保存密钥；保留手动刷新、失败退避与明确错误状态。
- 保留已封存的 0.2.2 标签及发布文件。

数据采用平台实际账单，不按单价或余额变化估算；统计全部 API Key，按北京时间 UTC+8 切日，不混合不同币种。平台账单接口未经公开文档化，可能变化或拒绝访问。

开发验证使用模拟协议响应和模拟额度 UI；实际账户需在设置内配置有效的平台凭证后联调。尚未创建 0.3.0 发布标签或上传 Release 资产。
