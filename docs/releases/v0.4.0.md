# Codex Quota Bar 0.4.0

Windows 10/11 x64 原生程序。

## 本版更新

- 设置新增「Codex 用量」页：显示近 7 / 30 天本地 Token、会话数量与标准 API 等价费用估算，支持费用/Token、按天/小时切换和年度活跃热力图。
- 用量可按模型、项目、会话和可确认的账户归属分组；支持列表翻页、项目下钻、会话明细与日期筛选。
- 额度详情显示接口返回的月度及模型专属额度，新增额度历史曲线和均匀消耗参考线。历史按账户、工作区及重置周期区分，从有效采样开始积累。
- 本地日志采用增量读取和重复会话去重；无法确认的子会话继承边界、未知价格和未覆盖记录会单独标明。统计页及额度浮窗沿用系统毛玻璃。
- 前台应用全屏时隐藏该显示器上的 Codex、DeepSeek 任务栏组件及悬浮详情，退出全屏后恢复。
- 高级设置新增「检查更新」。安装版可在确认后下载、校验并覆盖更新到原目录，随后重新启动；便携版可打开发布页。

## 功能与数据范围

保留 Codex 5 小时/周额度、DeepSeek 余额与消费明细、多屏布局、拖动避让、外观配色和透明度、托盘及自动/手动刷新功能。

费用为本机日志对应的标准 API 等价估算，不是订阅实际扣费或完整账户账单；额外额度取决于接口返回。本地未记录的任务及未读过的压缩历史不包含在统计中。毛玻璃不可用时使用纯色回退。

设置和统计数据保存在用户数据目录；DeepSeek 凭据保存在 Windows 凭据管理器。覆盖安装保留这些数据及 Codex 登录信息。
