# Codex Quota Bar 0.3.6

Windows 10/11 x64 原生版本，本版本为最新版；稳定版为 0.3.5。

- DeepSeek 一键获取凭证支持 Microsoft Edge 和 Google Chrome，按 Windows 默认浏览器打开平台并读取对应浏览器最近使用配置的登录态，无需安装扩展或 WebView2。
- 获取成功后自动保存凭证、刷新查询并显示确认弹窗；失败时提醒检查是否已在默认浏览器网页版登录 DeepSeek 平台。弹窗采用统一浅深色毛玻璃样式，高度随文字数量调整。
- 包含 DeepSeek 当日每小时消耗柱状图及毛玻璃凭证填写说明。

自动获取目前支持 Edge / Chrome 标准用户目录中的 LevelDB 存储，不支持无痕窗口、自定义用户数据目录或 SQLite 存储。其他默认浏览器仍可打开平台，凭证可手动填写。

验证：472 项核心检查、54 项 DeepSeek UI 检查；安装和便携包使用隔离目录验证。预览使用模拟数据。

提供 Setup EXE、Portable ZIP 和 SHA256SUMS.txt；无需额外运行库。
