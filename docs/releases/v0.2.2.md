# Codex Quota Bar 0.2.2

任务栏显示修复与额度选择更新，仍为无需 .NET 或额外 C++ 运行库的 Windows x64 原生应用。

- 修复打开 Windows 快速设置时额度图标被任务栏遮挡，任务栏重建后自动恢复。
- 悬浮详情标题右侧显示当前套餐，补齐 Pro Lite / Pro Max 等类型识别。
- 新增独立的 5 小时、周额度显示开关，同步影响任务栏、悬浮详情与预览。
- 默认 Plus 显示两项，Pro 系列仅显示周额度；支持恢复套餐默认。两项关闭时隐藏组件，仍可通过设置快捷方式重新打开。
- 切换“在图标上展示余量”时重播预览动画，遵循样式与系统动画设置。
- 沿用现有设置；手动开启但账户未返回的额度显示 `--`。

提供可选择安装路径的 Setup.exe、解压即用的 Portable ZIP，以及 SHA256SUMS.txt。程序尚未代码签名。

验证：362 项原生核心检查、95 项 UI 检查、隔离的中文/空格自定义路径安装与卸载、ZIP 内容及 PE 系统依赖检查。UI 测试与文档插图均使用模拟额度；本机仅验证已连接屏幕，Windows 快速设置真实面板及其他任务栏形态仍需手动回归。
