# Codex Quota Bar 0.3.2

- 安装向导可选添加桌面快捷方式，默认不勾选。双击快捷方式打开设置。
- 设置新增「高级 → 打开文件夹」和「外观 → 底色不透明度」，调整底色时可实时预览。
- 拖动重叠达到较小组件面积的 50% 时，另一组件提前让位。未达到阈值时，松手只让拖动的组件贴靠。
- 统一安装版与便携版的卸载入口。便携版校验随附文件并保留目录中的无关文件。

Windows 10/11 x64。提供安装包、便携 ZIP 和 SHA-256 校验文件。

验证通过 443 项核心检查、242 项界面检查，以及隔离安装、快捷方式和卸载测试。
