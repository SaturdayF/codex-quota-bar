# Codex Quota Bar 0.4.2

Windows 10/11 x64 原生程序。

## 本版更新

- Codex 详情将 5 小时和每周额度并排显示，加入今日及近 7 天 Token 汇总、今日输入/缓存输入/输出和请求数，并将额度历史置于用量汇总与每日 Token 曲线之间。
- 额度、Token 和费用趋势采用平滑曲线；每日 Token 支持悬浮查看日期及完整数量，提示仅显示文字。鼠标离开详情后保留 1.5 秒，移回会重新计时。
- Codex 用量页同时显示费用与 Token 趋势，按实际分组行数调整页面高度，移除底部固定留白，仅在需要时显示分页。
- 自动更新安装包下载总时限延长至 5 分钟；下载按钮显示百分比，悬停显示「取消」，支持取消下载。
- 多设备同步状态显示具体失败原因；本机托管地址优先显示物理网卡和部分 VPN 地址，排除链路本地及 198.18 地址，最多显示三个候选地址；设备列表标注「本机」。

## 功能与数据范围

包含本地 Codex 用量统计、额度详情与采样历史、多设备 Hub 同步、DeepSeek 余额与用量、多屏和外观设置，以及全屏隐藏和更新检查。设置与详情沿用系统毛玻璃。

Token 统计来自本机已采集会话日志，费用为标准 API 等价估算，不代表订阅实际扣费。缓存输入包含在输入中；未覆盖记录保留提示或曲线断点。平滑连线用于展示采样之间的变化，不增加历史记录或预测未来额度。

下载百分比表示安装包接收进度，完成后仍需校验并启动安装流程。同步连接与数据范围见 [Hub 同步说明](https://github.com/SaturdayF/codex-quota-bar/blob/v0.4.2/docs/HUB_SYNC.md)。
