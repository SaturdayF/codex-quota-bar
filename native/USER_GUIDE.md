# Codex Quota Bar 0.3.0

C++ 原生 Windows x64 额度组件，无需 .NET 或另外安装 C++ 运行库。

0.3.0 为开发版本，0.2.2 的历史源码和发布资产保持封存。

## 任务栏布局

“常规 → 图标自动避让”默认开启。组件避开可识别的任务栏按钮和通知区域，联合查找整条任务栏的空位，必要时重新安排两个组件。总空间不足时暂时隐藏放不下的组件，有空位后恢复；关闭后允许手动摆放。

按住鼠标左键拖动，可跨过任务栏图标移动到另一端。拖动时允许覆盖另一组件，松手时重叠达到较小组件面积的 50% 则交换，未达到则回原位；没有重叠则在落点附近查找空位。布局在本次运行中保留，重新启动恢复默认位置。

松手后以约 240 毫秒减速移动到最终位置，交换时两个组件同时移动。再次按住可立即继续拖动，遵循 Windows 动画效果设置。

## DeepSeekHarness

设置中选择 DeepSeekHarness，填写平台 userToken 并保存。“自动跟随 DeepSeekHarness”默认开启，组件平时待机，检测到 Harness 桌面进程后才显示和查询；应用退出后隐藏并取消本轮查询。最小化或留在托盘仍视为运行，不识别仅在浏览器或命令行运行的 Harness。

“未启动时也显示余额”默认关闭。开启并保存后，不运行 Harness 也会显示并刷新余额和账单，Harness 退出后仍保持显示。两个开关独立，均关闭时不显示、不查询。

平台凭证用于查询同一账户的余额、北京时间当日消费和模型明细。程序不读取或保存 API Key，也不收集账号密码。点击“凭证填写说明”可查看在浏览器中获取 userToken 的步骤。userToken 属于平台登录凭证。

任务栏组件独立于 Codex 是否运行，悬浮显示当日各模型的费用、请求数、缓存输入与输出 Token。按北京时间 UTC+8 零点切日，聚合账户用量，使用平台实际账单，不估算单价；不同币种不相加。详情卡模型较多时可滚轮翻阅。

凭证由 Windows 凭据管理器保护，不写入设置 JSON。输入留空保留已有凭证；“清除凭证”在保存后生效。默认每分钟更新，支持 2 / 5 分钟与手动刷新。平台接口可能调整，凭证过期或读取失败会提示；旧数据保留原更新时间，不把失败当作零消费。已完成一次真实账户的接口只读验证，文档截图和回归测试使用模拟数据。

安装版卸载并选择删除设置时同时删除 DeepSeek 凭证；便携版删除目录前可在设置中清除凭证。Codex 的登录数据不受影响。

## 使用

- 安装器：双击 Setup.exe，可以选择安装路径；提供登录启动、设置快捷方式和原生卸载。
- 便携 ZIP：完整解压，运行 CodexQuotaBar.exe；需要自动运行时，在设置的“常规”页启用登录启动。
- 本机需要已有 Codex CLI，并通过 ChatGPT 账户登录；自动查找失败时，在“高级”页指定 codex.exe。
- 打开任一 ChatGPT / Codex 桌面应用时显示；两者完全退出后停止读取和显示，轻量监听器继续等待。
- 悬浮查看详情，右键打开设置，左键横向拖动。设置可选择显示器、七种样式、两种颜色、大小、余量、百分号、动画和刷新间隔。
- 常规设置可分别选择是否显示 5 小时、周额度，对所有样式生效。默认 Plus 显示两项，Pro 系列（`pro`、`prolite`、`promax`）只显示周额度；点击“恢复套餐默认”可重新跟随套餐。
- 两项均关闭会隐藏任务栏组件，仍可从设置快捷方式或 `CodexQuotaBar.exe --settings` 打开设置。手动开启但账户未返回的额度显示 `--`，不会虚构额度。
- 外观页切换“在图标上展示余量”时重播模拟预览动画；关闭该样式的动画或关闭 Windows 动画时保持静态。
- 悬浮详情标题右侧显示 CLI 当前登录账户的套餐类型；尚未读取到时显示“套餐未知”。

## 升级、退出与卸载

先退出 0.1.0 监听器再启动新版本；同一时间只运行一个监听器。0.3.0 沿用原有设置，不删除旧安装。设置在当前用户 LocalAppData/CodexQuotaBar/settings.json。

“高级 → 退出额度工具”停止监听。便携版退出后删除解压目录即可；安装版可使用“高级 → 卸载程序”或 Windows 应用列表中的卸载入口。设置中的卸载会确认后删除本工具和配置，不删除 ChatGPT / Codex 及它们的登录数据。旧卸载器可能清除共用启动项，卸载旧版后可在新版中重新启用。

## 读取与边界

通过本地 Codex app-server 查询已登录账户的额度，不抓取 Cookie、不解析 auth.json、不创建聊天或模型推理。多个应用登录不同账户时，展示的是 CLI 账户额度。默认每 30 秒读取，失败时保留最后成功数据并退避重试，不保证服务端秒级同步。

主要适配标准水平任务栏；自动隐藏、竖直及第三方任务栏未专项验证。程序尚未代码签名。MIT 许可与 JSON 库许可随包提供；这是独立工具，与 OpenAI 无隶属关系。
