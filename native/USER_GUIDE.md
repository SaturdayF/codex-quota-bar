# Codex Quota Bar 使用指南

适用于 0.3.4，支持 Windows 10/11 x64。

安装时可选“添加桌面快捷方式”，双击快捷方式打开设置。“高级 → 打开文件夹”可在资源管理器中打开正在运行的程序目录。“外观 → 底色不透明度”同时控制两个任务栏组件的背景，0% 为透明，滑块调整会更新设置预览。「Codex 图标不透明度」独立控制额度图形和数字，范围为 10% 到 100%。

拖动时，与另一组件重叠达到未拖动组件面积的一半，另一组件会预览移动到对侧。松手确认交换，两组件相邻落位，退出重叠范围会恢复预览位置。重叠不足时松手只让被拖动的组件贴靠，空间不足时在任务栏其他空位落位。

## 安装与启动

安装版运行 Setup EXE，选择当前用户可写的专用目录。便携版完整解压 ZIP 后运行 `CodexQuotaBar.exe`。两种版本均无需额外运行库。

Codex 额度需要本机 Codex CLI 已通过 ChatGPT 账户登录。可在“高级”页指定 CLI 路径。ChatGPT 或 Codex 桌面进程运行时显示 Codex 组件，两者均退出后收起；后台监听器继续等待启动。

## 任务栏操作

程序运行时在系统托盘显示应用图标，右键可选择“打开设置”或“退出 Codex Quota Bar”，点击图标也可打开设置。即使两个任务栏组件均已隐藏，托盘入口仍可使用。Windows 可能将图标收纳到托盘的上箭头菜单中。

- 悬浮：显示额度或余额详情。
- 右键：打开设置。
- 按住左键：横向拖动组件。
- 滚轮：在 DeepSeek 详情中翻阅更多模型。

自动避让开启时，组件会寻找任务栏空位，空间不足时暂时隐藏。拖动时可越过图标。松手后的落位会避开原生任务栏图标。松手后使用平滑过渡，位置在本次运行中保留。

## Codex 设置

设置默认浅色，可在“外观”切换浅色或深色。滑动条支持拖动及方向键调整；右侧细长滚动条支持拖动。设置、顶栏与悬浮详情使用系统实时毛玻璃，移动窗口或后方内容变化时自动更新。Windows 11 22H2 及以上使用 Desktop Acrylic，较早版本使用兼容模糊；系统关闭合成或启用高对比度时使用纯色背景。

“外观”页提供七种样式、独立颜色、60%–140% 显示大小、余量图形、百分号、H/W 标记和动画。预览使用模拟数据，点击“保存更改”应用。

“常规”页选择屏幕，分别开关 5 小时和周额度，并设置图标避让与登录启动。恢复套餐默认后，Plus 显示两项，Pro 系列默认显示周额度。两项均关闭时隐藏 Codex 组件。

“高级”页可选择 15 秒、30 秒、1 分钟、2 分钟或 5 分钟刷新间隔，默认 30 秒。未返回的额度显示 `--`，读取失败时显示状态并重试。详情中的套餐和额度属于 CLI 当前登录账户。

## DeepSeek 设置

1. 在“DeepSeek 相关设置”页打开 DeepSeek 平台并登录。
2. 在浏览器开发者工具的 Application / 应用 → Local Storage / 本地存储 → `https://platform.deepseek.com` 中找到 `userToken`。
3. 填入令牌或含 `value` 的 JSON 值，保存设置。

凭证保存在 Windows 凭据管理器。输入留空保留已有凭证；“清除凭证”在保存后生效。

默认随 Harness 桌面进程显示；“未启动时也显示余额”可独立开启。两个显示开关均关闭时停止显示和查询。刷新间隔可选 1 / 2 / 5 分钟，支持手动刷新。

任务栏显示余额和当日消费；详情按模型显示费用、请求数、缓存输入及输出 Token。账单按北京时间零点切日，不同币种分开显示。平台数据延迟或凭证失效时会显示状态。

「显示 DSH 图标」默认开启。关闭后仅隐藏文字左侧的 DSH 标识，保留余额、当日消费和悬浮详情，组件宽度自动缩短；保存更改后生效。

## 退出与卸载

“高级 → 退出额度工具”停止程序及后台监听。

安装版可使用“高级 → 卸载程序”或 Windows 应用列表卸载。便携版也支持设置中的卸载按钮，等待程序退出后清理随包文件。两种方式均保留目录中额外放入的文件。

设置中的卸载操作会清理本工具配置和 DeepSeek 凭证。便携版还会清理本工具的登录启动项；其卸载流程需要系统 PowerShell，执行受策略限制时，可退出后手动删除程序文件。ChatGPT / Codex 的安装与登录数据不受影响。

设置文件位于 `%LOCALAPPDATA%\CodexQuotaBar\settings.json`。

## 适用范围

主要适配标准水平任务栏，自动隐藏、竖直和第三方任务栏尚未专项验证。任务栏嵌入受限时使用置顶备用窗口。上游协议和系统策略可能影响功能。程序尚未代码签名。
