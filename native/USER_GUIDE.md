# Codex Quota Bar 0.2.1

C++ 原生 Windows x64 额度组件，无需 .NET 或另外安装 C++ 运行库。

完整图文说明：https://github.com/SaturdayF/codex-quota-bar

## 使用

- 安装器：双击 Setup.exe，可以选择安装路径；提供登录启动、设置快捷方式和原生卸载。
- 便携 ZIP：完整解压，运行 CodexQuotaBar.exe；需要自动运行时，在设置的“常规”页启用登录启动。
- 本机需要已有 Codex CLI，并通过 ChatGPT 账户登录；自动查找失败时，在“高级”页指定 codex.exe。
- 打开任一 ChatGPT / Codex 桌面应用时显示；两者完全退出后停止读取和显示，轻量监听器继续等待。
- 悬浮查看详情，右键打开设置，左键横向拖动。设置可选择显示器、七种样式、两种颜色、大小、余量、百分号、动画和刷新间隔。
- Pro 系列（`pro`、`prolite`、`promax`）按本工具的偏好只显示周额度；其他套餐仅返回周额度时也使用单周布局，不显示不存在的 5 小时额度。
- 悬浮详情标题右侧显示 CLI 当前登录账户的套餐类型；尚未读取到时显示“套餐未知”。

## 升级、退出与卸载

先退出 0.1.0 监听器再启动新版本；同一时间只运行一个监听器。0.2.1 沿用原有设置，不删除旧安装。设置在当前用户 LocalAppData/CodexQuotaBar/settings.json。

“高级 → 退出额度工具”停止监听。便携版退出后删除解压目录即可；安装版可使用“高级 → 卸载程序”或 Windows 应用列表中的卸载入口。设置中的卸载会确认后删除本工具和配置，不删除 ChatGPT / Codex 及它们的登录数据。旧卸载器可能清除共用启动项，卸载旧版后可在新版中重新启用。

## 读取与边界

通过本地 Codex app-server 查询已登录账户的额度，不抓取 Cookie、不解析 auth.json、不创建聊天或模型推理。多个应用登录不同账户时，展示的是 CLI 账户额度。默认每 30 秒读取，失败时保留最后成功数据并退避重试，不保证服务端秒级同步。

主要适配标准水平任务栏；自动隐藏、竖直及第三方任务栏未专项验证。程序尚未代码签名。MIT 许可与 JSON 库许可随包提供；这是独立工具，与 OpenAI 无隶属关系。
