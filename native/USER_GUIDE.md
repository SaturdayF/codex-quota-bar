# Codex Quota Bar 使用指南

适用于 0.4.3，支持 Windows 10/11 x64。

安装时可选“添加桌面快捷方式”，双击快捷方式打开设置。“高级 → 打开文件夹”可在资源管理器中打开正在运行的程序目录。“外观 → 底色不透明度”同时控制两个任务栏组件的背景，0% 为透明，滑块调整会更新设置预览。「Codex 图标不透明度」独立控制额度图形和数字，范围为 10% 到 100%。

拖动时，与另一组件重叠达到未拖动组件面积的一半，另一组件会预览移动到对侧。松手确认交换，两组件相邻落位，退出重叠范围会恢复预览位置。重叠不足时松手只让被拖动的组件贴靠，空间不足时在任务栏其他空位落位。

## 安装与启动

安装版运行 Setup EXE，选择当前用户可写的专用目录。便携版完整解压 ZIP 后运行 `CodexQuotaBar.exe`。两种版本均无需额外运行库。

在「高级 → 检查更新」查询 GitHub 的正式版。安装版发现新版本后，可确认下载并覆盖安装到当前目录，完成后程序会重新启动。请先保存设置页中的更改。便携版发现新版本时可打开发布页下载新的便携包。

Codex 额度需要本机 Codex CLI 已通过 ChatGPT 账户登录。可在“高级”页指定 CLI 路径。ChatGPT 或 Codex 桌面进程运行时显示 Codex 组件，两者均退出后收起；后台监听器继续等待启动。

## 任务栏操作

程序运行时在系统托盘显示应用图标，右键可选择“打开设置”或“退出 Codex Quota Bar”，点击图标也可打开设置。即使两个任务栏组件均已隐藏，托盘入口仍可使用。Windows 可能将图标收纳到托盘的上箭头菜单中。

- 悬浮：显示额度或余额详情。
- 右键：打开设置。
- 按住左键：横向拖动组件。
- 滚轮：在 DeepSeek 详情中翻阅更多模型。

其他应用在前台全屏时，该屏幕上的 Codex 和 DeepSeek 组件会自动隐藏，悬浮在原位置也不会显示详情。退出全屏后，组件按原有显示条件恢复。

自动避让开启时，组件会寻找任务栏空位，空间不足时暂时隐藏。拖动时可越过图标。松手后的落位会避开原生任务栏图标。松手后使用平滑过渡，位置在本次运行中保留。

## Codex 设置

设置默认浅色，可在“外观”切换浅色或深色。滑动条支持拖动及方向键调整；右侧细长滚动条支持拖动。设置、顶栏与悬浮详情使用系统实时毛玻璃，移动窗口或后方内容变化时自动更新。Windows 11 22H2 及以上使用 Desktop Acrylic，较早版本使用兼容模糊；系统关闭合成或启用高对比度时使用纯色背景。

“外观”页提供七种样式、独立颜色、60%–140% 显示大小、余量图形、百分号、H/W 标记和动画。预览使用模拟数据，点击“保存更改”应用。

“常规”页选择屏幕，分别开关 5 小时和周额度，并设置图标避让与登录启动。恢复套餐默认后，Plus 显示两项，Pro 系列默认显示周额度。两项均关闭时隐藏 Codex 组件。

“高级”页可选择 15 秒、30 秒、1 分钟、2 分钟或 5 分钟刷新间隔，默认 30 秒。未返回的额度显示 `--`，读取失败时显示状态并重试。详情中的套餐和额度属于 CLI 当前登录账户。

## Codex 用量与额度历史

打开设置中的「Codex 用量」，选择近 7 天或近 30 天，查看已记录的 Token、会话数量和标准 API 等价费用估算。费用/Token、按天/按小时可分别切换；每小时视图显示所选日期，未选择日期时显示今日。向下滚动可查看年度活跃热力图及模型、项目、会话、账户归属分组。点击已覆盖的热力图日期查看当日统计，「返回全部」清除日期或项目筛选。

点击项目行查看该项目的会话；点击会话或模型行查看明细。分组列表每页五项，可用「上一页／下一页」查看其余记录。账户归属仅使用日志中明确记录的信息，按编号区分；无法确认归属的记录列为「归属未知」。旧记录不会因当前账户重新登录而自动改归属。

「刷新统计」在后台增量读取本机 Codex 的 `sessions`、`archived_sessions` JSONL 日志；默认目录为 `%USERPROFILE%\.codex`，设置了 `CODEX_HOME` 时使用该目录。大文件分批读取，未完成时会提示覆盖不完整并继续补齐。子会话无法确认继承边界时不计入不确定记录，并提示覆盖不完整。压缩的 `.zst` 文件不会被解压；同路径日志压缩前已读到的用量可沿用本地缓存，未读过的压缩历史无法补齐。会话标题来自显式标题索引，不从提示词正文生成。

Token 总量为输入加输出；缓存输入属于输入的子集，推理属于输出的子集。费用按 2026-11-14 核对的标准 API 单价估算，已识别的请求档位和长上下文规则参与计算；未记录档位时按标准档估算，缓存写入在有对应价格时按 30 分钟档估算。未知模型或无法确认请求价格时保留 Token，并标为价格未知。部分已定价时显示 `≥`。这些金额不是订阅实际扣费，也不代表完整账户账单；没有本地记录的云端任务不包含在统计中。

点击「额度详情」，或悬浮在任务栏 Codex 组件上，可查看当前额度和接口提供的额外窗口。未返回的月度、Spark 等额度不会生成占位数值。切换「额度历史」后选择窗口，实线显示已采样的剩余额度，虚线只是均匀消耗参考，不是预测。历史从新版本取得有效采样时开始，最后采样之后不延长实线；账户、工作区、套餐和重置周期分别隔离。无法确认账户与工作区时暂不记录历史。

统计缓存与额度历史分别保存在 `%LOCALAPPDATA%\CodexQuotaBar\codex-usage-cache.json` 和 `codex-quota-history.json`。它们不包含登录令牌或对话正文；项目路径及会话标识属于本地统计信息。程序不会修改源会话日志。新统计页及额度浮窗使用与设置相同的系统实时毛玻璃，系统不支持时沿用纯色回退。

## DeepSeek 设置

1. 在“DeepSeek 相关设置”页点击“一键获取凭证”，程序使用 Windows 默认浏览器（Edge / Chrome）最近使用的配置打开 DeepSeek 平台网页。
2. 已登录时自动读取并验证 `userToken`，成功后自动返回 DeepSeek 设置页并保存凭证，显示“获取 Token 成功”弹窗。失败弹窗会提醒检查是否已在 默认浏览器的网页版登录 DeepSeek 平台；登录后等待几秒再获取。弹窗高度随提示文字数量调整。
3. 也可手动获取：在浏览器中登录后按 F12，在 Application → Local Storage 找到 `userToken`，复制并粘贴到“平台登录凭证”。

凭证保存在 Windows 凭据管理器。一键获取成功后立即保存并刷新查询；其他设置和手动填写的凭证仍需点击“保存更改”。输入留空保留已有凭证；“清除凭证”在保存后生效。

自动获取不需要安装浏览器扩展。当前支持 Edge / Chrome 标准目录中的 LevelDB 本地存储，不支持 InPrivate、自定义用户数据目录或 SQLite 存储；权限或格式不兼容时请手动填写。程序仅以只读方式解析浏览器存储，不创建浏览器数据副本；读取结果只用于 DeepSeek 官方平台的验证与查询。

默认随 Harness 桌面进程显示；“未启动时也显示余额”可独立开启。两个显示开关均关闭时停止显示和查询。刷新间隔可选 1 / 2 / 5 分钟，支持手动刷新。

任务栏显示余额和当日消费；详情按模型显示费用、请求数、缓存输入及输出 Token，并以柱状图展示当日每小时消耗。账单按北京时间零点切日，不同币种分开显示。平台数据延迟或凭证失效时会显示状态。

“凭证填写说明”在设置内打开同款毛玻璃说明弹窗，可拖动，回车或 Esc 关闭。

「显示 DSH 图标」默认开启。关闭后仅隐藏文字左侧的 DSH 标识，保留余额、当日消费和悬浮详情，组件宽度自动缩短；保存更改后生效。

## 退出与卸载

“高级 → 退出额度工具”停止程序及后台监听。

安装版可使用“高级 → 卸载程序”或 Windows 应用列表卸载。便携版也支持设置中的卸载按钮，等待程序退出后清理随包文件。两种方式均保留目录中额外放入的文件。

设置中的卸载操作会清理本工具配置和 DeepSeek 凭证。便携版还会清理本工具的登录启动项；其卸载流程需要系统 PowerShell，执行受策略限制时，可退出后手动删除程序文件。ChatGPT / Codex 的安装与登录数据不受影响。

设置文件位于 `%LOCALAPPDATA%\CodexQuotaBar\settings.json`。

## 适用范围

主要适配标准水平任务栏，自动隐藏、竖直和第三方任务栏尚未专项验证。任务栏嵌入受限时使用置顶备用窗口。上游协议和系统策略可能影响功能。程序尚未代码签名。

设置与详情使用系统实时毛玻璃。省电模式（Battery Saver）下系统会关闭半透明与模糊，毛玻璃不可用，界面回退为不透明底色；退出省电模式后自动恢复。

## 多设备同步（0.4.1）

0.4.3 的「Codex 用量」页可选择本机日志、全部设备或指定设备；共享来源显示今日、本月、累计统计，以及已同步的模型、项目、会话和设备分组。连接 Hub 后默认全部设备，可在“同步额度”中查看各账户的额度采样。额度百分比不相加，远端额度不会替换本机当前账户。

共享每日趋势保留各来源上报日期，最多显示最近 30 个已记录日期；源记录缺失不代表零用量。累计视图不提供完整会话数量。按小时分析和导入/导出 CSV 在选择本机日志时使用。Windows 补充会话、模型 Token 分项、项目标签、归一化额度和采集状态上传；无可靠来源的精确时刻、上下文、消息数和吞吐信息保持未知。

在设置的「多设备同步」中选择仅本机、连接 Hub 或本机托管。托管时生成并应用共享密钥；其他 Token Monitor 设备使用显示的地址和相同密钥连接，每台设备 ID 必须不同。连接设置用本页的「应用同步设置」立即生效。关闭设置后继续运行，退出程序会停止 Hub。

同步页显示所有设备已记录的今日、本月、累计用量和可翻页的每日/月度历史。HTTP 不加密传输；仅在可信网络/VPN 中使用，或连接自行配置的 HTTPS Hub。程序不自动配置防火墙。所有设备连接同一个 Hub，多个独立 Hub 不会互相同步。

Windows 首次采集最多覆盖扫描器支持的近 365 天；启用同步后独立保留已观察到的每日统计，不能恢复之前已丢失的日志。详细每日同步最近 370 天，月度历史保留更早月份；跨设备重复日志直接相加。费用是已知价格部分的 API 等价估算。共享标题、价格/别名及订阅账本不属于本版兼容范围，macOS 具体版本仍需实际连接确认。

共享密钥独立保存于 Windows 凭据管理器；原有登录和 DeepSeek 凭据不参与上传。Hub 最多 128 台设备、16 MiB 持久化数据，单次上传 2 MiB；本机历史最多 180,000 条每日分组、64 MiB，达到上限时保留原结果并提示同步失败。

## 自动更新下载（0.4.2）

确认自动更新后，安装包下载总时限为 5 分钟。高级设置中的「检查更新」按钮显示当前下载百分比；鼠标移入按钮时文字变为「取消」，移开后恢复最新百分比。点击可取消下载，取消期间显示「正在取消…」，结束后恢复「检查更新」。百分比表示安装包接收进度，100% 后仍需完成校验和安装交接。

Codex 详情中的 5 小时与每周额度并排显示。鼠标离开组件和浮窗后，浮窗保留 1.5 秒；期间移回会重新计时。详情还显示近 7 天每日 Token 曲线、今日与近 7 天用量，以及今日输入、缓存输入、输出和请求数。数据来自本机已采集的会话日志，缓存输入已包含在输入中，统计不代表订阅额度或实际账单；未覆盖的历史会明确提示。

额度历史已合并到当前额度详情，可从额度窗口菜单选择 5 小时、每周或其他可用窗口。额度与 Token 曲线在真实采样点之间平滑连接；连接形状仅用于阅读，不代表新增采样或未来预测。用量页的费用曲线使用左侧 USD 刻度，蓝色 Token 曲线使用图上标注的 Token 顶部刻度；选择 Token 后使用左侧 Token 刻度。

鼠标移到详情浮窗或 Codex 用量页的 Token 趋势图上，可查看对应日期（按小时模式为对应小时）及完整 Token 数量。缺失记录显示未覆盖提示。用量页底部随实际分组行数调整，超过五项时显示分页。

“今日 Token”在打开详情时逐位滚动至当前值，显示数值变化时平滑过渡，K/M/B 单位保持固定。此效果遵循“外观”中当前样式的动画开关；Windows 关闭动画时直接显示当前值。

## CSV 备份与恢复（0.4.3）

在「Codex 用量」点击「导出 CSV」选择保存位置，导出全部当前已采集的用量，而非只导出当前日期筛选。备份包含请求时间、会话/项目/模型/账户归属、输入/缓存输入/缓存写入/输出/推理 Token、请求数、已记录的费用及定价状态、会话标题和额度采样历史。登录凭证与应用设置不包含在 CSV 中。

点击「导入 CSV」选择本程序导出的备份，校验后合并保存；重启、刷新及详情浮窗都能读取恢复的数据。实时额度仍由平台读取。相同会话、时间、模型、服务层级、请求数和 Token 分项的重复记录按出现次数合并，不会因反复导入相同备份而累加。原始日志后来修改了 Token 内容时，无法把修改后的记录可靠识别为同一请求。

恢复档案保存在本机数据目录的 `codex-restored-data.csv`，支持最多 140,000 条用量明细和 24,000 条额度采样，文件上限 128 MiB；超限或格式不符会拒绝导入并保留已有数据。CSV 使用带 BOM 的 UTF-8，包含版本、记录类型和列名；请导入原始备份，避免用表格软件另存造成大整数或时间精度丢失。CSV 中的文字字段做可逆的公式保护；导入不重新计算已记录费用。
